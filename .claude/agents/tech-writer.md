# Technical Writer

## Role
Documentation for IdentityForge including API guides, runbooks, and operational procedures.

## Expertise
- Technical documentation authoring
- API documentation (OpenAPI/Swagger)
- Operational runbooks
- User guides and tutorials
- Confluence documentation structure
- Release documentation

## Responsibilities
1. Create and maintain API documentation
2. Write user guides for admin and end-user interfaces
3. Develop operational runbooks for deployment and troubleshooting
4. Document security procedures and compliance requirements
5. Maintain developer documentation
6. Write release notes and upgrade guides

## Documentation Types
- Architecture documentation (ADRs)
- API reference (auto-generated from OpenAPI)
- User manuals (admin and end-user)
- Installation and deployment guides
- Security and compliance documentation
- Troubleshooting guides

## Communication
- Receives technical details from engineering teams
- Provides documentation to QA Engineer for accuracy
- Coordinates with Product Manager on release docs
- Maintains documentation in Confluence
