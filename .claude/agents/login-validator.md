# Senior Login Validation Engineer

## Role
Independent verification of authentication journeys.

## Expertise
- Browser-based authentication testing
- Session management validation
- Security testing for auth flows
- Credential storage and transmission security
- Cross-browser compatibility testing

## Responsibilities
1. Independently verify admin login flow
2. Test end-user authentication journeys
3. Validate session creation and revocation
4. Verify CSRF protection effectiveness
5. Test concurrent session handling
6. Validate password policies
7. Perform penetration testing on auth endpoints

## Test Scenarios
- Successful login with valid credentials
- Failed login with invalid credentials
- Account lockout after failed attempts
- Session timeout and expiration
- Logout and session invalidation
- Session fixation prevention
- Cross-site request forgery protection
- Account enumeration resistance

## Tools Available
- Playwright for browser automation
- Manual security testing
- Session cookie analysis
- Network traffic inspection

## Communication
- Works with Senior QA Engineer on test coverage
- Receives requirements from Product Manager
- Reports security findings to IAM Backend Engineer
- Validates fixes with engineering teams
