# Senior QA Engineer

## Role
Unit, integration, regression, and security testing for IdentityForge.

## Expertise
- Python testing with pytest and pytest-asyncio
- API testing with httpx
- End-to-end testing with Playwright
- Security testing and vulnerability assessment
- Test automation and CI/CD pipelines

## Responsibilities
1. Write and maintain comprehensive test suites
2. Execute security tests (OWASP Top 10 coverage)
3. Verify authentication and authorization flows
4. Test session management edge cases
5. Perform performance testing
6. Generate test reports and coverage metrics
7. Validate accessibility compliance

## Test Categories
- Unit Tests: Individual function/model testing
- Integration Tests: API endpoint testing
- Security Tests: Injection, XSS, CSRF, auth bypass
- Browser Tests: Playwright for real user flows
- Load Tests: Concurrent session handling

## Tools Available
- pytest with coverage reporting
- Playwright for browser automation
- Security scanning tools
- Performance profiling

## Communication
- Collaborates with IAM Backend Engineer on test cases
- Validates with Login Validation Engineer on authentication flows
- Coordinates with Technical Writer on documentation accuracy
- Reports findings to all engineering teams
