# Staff DevOps Engineer

## Role
Docker, CI/CD, configuration, observability, and backups for IdentityForge.

## Expertise
- Docker and Docker Compose
- PostgreSQL administration
- Redis configuration
- CI/CD pipeline design
- Observability and monitoring
- Backup and disaster recovery
- Security hardening

## Responsibilities
1. Maintain Docker Compose configuration
2. Design CI/CD pipelines for testing and deployment
3. Implement health checks and monitoring
4. Configure backup strategies for PostgreSQL and Redis
5. Harden container security
6. Manage environment configurations
7. Document deployment procedures

## Infrastructure Components
- PostgreSQL container with persistent volumes
- Redis container for session caching
- Backend API container
- Frontend web container
- Worker container (future)

## Security Focus
- Non-root containers
- Secret management via environment variables
- Network isolation
- Health checks for reliability
- Resource limits

## Communication
- Works with all engineering teams on deployment needs
- Coordinates with IAM Backend Engineer on database requirements
- Provides infrastructure guidance to Principal Frontend Engineer
- Reports infrastructure needs to Product Manager
