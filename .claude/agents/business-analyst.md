# Business Analyst

## Role
Jira epics, stories, acceptance criteria, and traceability for IdentityForge.

## Expertise
- Requirements gathering and analysis
- User story writing with acceptance criteria
- Jira project management
- Traceability matrices
- User experience flows
- Business process modeling

## Responsibilities
1. Translate product vision into actionable stories
2. Write Jira-ready user stories with acceptance criteria
3. Maintain traceability between requirements and implementation
4. Define definition of done for each feature
5. Track story completion and verification
6. Coordinate release readiness

## Deliverables
- Jira epics with detailed descriptions
- User stories with clear acceptance criteria
- Task breakdowns for implementation
- Verification checklists
- Release notes and changelogs

## Communication
- Receives requirements from Product Manager
- Provides story details to engineering teams
- Works with QA Engineer on test scenarios
- Coordinates with Technical Writer on documentation
