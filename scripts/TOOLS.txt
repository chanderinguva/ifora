Tools used by `make check` (install them yourself; nothing here installs software for you)

Python (pinned in backend/requirements-dev.txt):
  pip install -r backend/requirements-dev.txt      # ruff, mypy, bandit, pip-audit
  The tools can also be run from a throwaway container, e.g.
    make check RUFF="docker run --rm -v $PWD:/src -w /src ifora-tools ruff"   (any image that has the tool)

Not Python, install locally:
  gitleaks   8.28.x  brew install gitleaks            secret scan (no code leaves the machine); .gitleaks.toml needs >= 8.28
                     or: docker run --rm -v "$PWD":/repo -w /repo zricethezav/gitleaks:v8.28.0 ...  (wrap as a `gitleaks` script on PATH)
  semgrep    1.97.0  pip install semgrep==1.97.0      community rules `p/python`; runs with --metrics=off
  trivy      0.5x    brew install trivy               only for `make images-scan` (optional)
  node/npm   24.x    brew install node                frontend lint, tsc, npm audit
  docker             Docker Desktop                   `make test-backend` runs pytest inside the ifora-api container

Notes
  - pip-audit and `npm audit` query the public advisory databases with package names and versions only.
  - semgrep downloads its rule pack; no source code is uploaded (--metrics=off).
  - Accepted findings live in .security-allowlist (reason + expiry required). Do not put secrets in it.
